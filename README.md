# Better Relationships

A handwritten piece on thinking, writing, and being real — scanned, cut into panels,
and set on the web.

**Read it:** https://nbolt2005.github.io/Relationships-writing/

By Noah Bolton, August 2026.

Format and title inspired by Lena Moses-Schmitt's
[*Daybook: Better Relationships*](https://daybook.substack.com/p/daybook-better-relationships).

---

`index.html` is a single self-contained page. `images/` holds the 22 panels cropped from
the original 8 handwritten sheets.
